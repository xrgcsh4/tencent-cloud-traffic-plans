## 腾讯云轻量服务器的月流量包，限制的到底是什么？

限制的是每月公网出方向流量总额，入站和内网不计入。

具体拆成三条：

- **计费方向**：只有服务器往外发数据才算，比如网页响应、文件下载、API 返回结果。用户上传文件、提交表单这类入站流量不限量，也不收费。
- **内网流量**：同地域的轻量服务器之间、以及同账号资源的内网通信，不计入流量包。
- **重置规则**：流量包按自然月重置，1 月没用完的额度不会攒到 2 月。系统自动抵扣，不需要手动操作。

明白这三条之后再看套餐数字，会发现实际能承载的业务比想象中多。一个每天几百人访问的博客，一个月出站流量通常也就几个 GB。

## 流量用超了会怎样？扣费标准和停机规则

超出部分按量计费，中国大陆地域 0.8 元/GB，中国香港地域 1 元/GB。

举个例子：套餐含 1000GB/月，某月实际出了 1300GB，超出 300GB，按大陆价格要补 300 × 0.8 = 240 元。这笔钱会自动从腾讯云账号余额扣除，不需要你逐笔确认。

余额不足时会怎样？这是很多介绍文章没讲清的地方：欠费后轻量服务器会被停机，停机期间无法对外提供服务，也就不会继续产生新的流量费。最坏情况是服务中断，不是账单无限滚下去。

两个降低风险的操作：

1. 在云监控里给流量设置告警阈值，用到 80% 时提醒，微信、短信、邮件都能收到。
2. 长期流量吃紧的，升级套餐或换不限流量款，比每个月补超量费划算。

## 关于流量限制的常见问题

**流量包月底用不完，能累积到下个月吗？**
不能。每月重置，未用完的额度清零，这也是不建议一次性买过大套餐的原因之一。

**往服务器上传文件、用户提交表单，算流量吗？**
不算。只统计公网出方向流量，入站不限量也不收费。

**流量超了会立刻停机吗？**
不会。先按量扣费，中国大陆 0.8 元/GB、中国香港 1 元/GB，账号余额不足时才停机，停机后不再产生新的流量费。

**可以单独购买流量包吗？**
腾讯云官方 FAQ 明确：不支持单独购买流量包，超出套餐额度直接按量计费。

**中国香港节点的超流量价格和大陆一样吗？**
不一样。大陆 0.8 元/GB，香港 1 元/GB，贵出 25%。主要用户在香港或海外、又可能跑超流量的，把这笔差价提前算进预算。

**内网流量怎么算？**
同地域的内网通信免费，不计入流量包。跨地域内网本身不通，也谈不上计费。
